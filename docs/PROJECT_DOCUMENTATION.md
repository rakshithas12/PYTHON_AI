## 2. Objective

The objective is to analyze student marks and attendance from a CSV file. The program summarizes individual and class performance so that a reader can identify totals, averages, grades, pass/fail outcomes, subject strengths, and top performers without manually calculating each result.

## 3. Technologies used

- Python 3.10+
- Pandas for reading and organizing CSV records as a DataFrame
- NumPy for numerical totals, means, and mark calculations
- Pytest for automated checks during development
- GitHub Actions for running tests when code is pushed or a pull request is opened

No machine-learning model or external AI service is used. The assignment describes advanced machine learning as unnecessary for this analysis project.

## 4. Dataset description

The repository includes `data/students.csv` with 20 fictional sample records. It contains a unique student ID, name, department, four subject marks, and attendance percentage. Marks and attendance use the 0–100 scale. The dataset contains only synthetic demonstration information.

## 5. Implementation

1. `load_students()` reads the CSV into a Pandas DataFrame.
2. The loader checks for required columns, non-empty identity fields, unique student IDs, numeric marks, and values between 0 and 100.
3. `process_students()` iterates over student rows and uses NumPy to calculate each total and average. It assigns a grade and pass/fail status.
4. `assign_grade()` applies the thresholds: A+ (90+), A (80–89.99), B (70–79.99), C (60–69.99), D (50–59.99), and F (below 50).
5. A student passes only when every subject mark is at least 40 and attendance is at least 75%.
6. `analyze_students()` calculates the class average, average attendance, pass/fail counts, highest and lowest averages, subject means, and a ranked top-performer table.
7. `format_report()` presents the results in labeled terminal sections. The optional `--export` argument writes processed rows to CSV.

## 6. Key features

- CSV loading and data validation
- Per-student total, average, grade, and pass/fail status
- Highest and lowest performer identification
- Subject-wise average analysis
- Overall average, pass/fail totals, and average attendance
- Configurable number of top performers
- Optional processed CSV export
- Automated unit tests and CI workflow
